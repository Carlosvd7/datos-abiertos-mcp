    Cómo funciona

    1. Un pipeline descarga los datos de las APIs oficiales, los limpia y los guarda en DuckDB con una descripción de cada tabla y columna.
    2. Un servidor MCP propio expone herramientas para listar tablas, describirlas y ejecutar SQL de solo lectura (una única consulta, sin escritura ni acceso a ficheros, 10 s y 500 filas como máximo).
    3. Claude usa esas herramientas para escribir y corregir el SQL, y responde solo con los números que devuelve la base de datos.
